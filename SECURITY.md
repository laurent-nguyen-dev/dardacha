# Sécurité

L'application ne collecte aucune donnée, ne demande aucun compte et ne fait
aucun appel réseau ; la seule donnée conservée est la liste des séances
terminées, sur le téléphone (docs/technique.md §6).

Pour signaler une vulnérabilité, utiliser l'onglet **Security → Report a
vulnerability** du dépôt GitHub plutôt qu'une issue publique.
