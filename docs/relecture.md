# Guide du relecteur

Dardacha apprend l'arabe parlé du quotidien en comparant trois variantes :
l'arabe littéraire moderne (MSA), la darija marocaine et le tounsi tunisien.
Tout le contenu est un premier jet, **pas encore relu par des locuteurs
natifs**. Ce guide s'adresse à eux : la relecture se fait directement dans
l'application.

## 1. Installer l'application (Android)

1. Sur le téléphone, ouvrir la page de la dernière version :
   https://github.com/laurent-nguyen-dev/dardacha/releases/latest
2. Toucher le fichier `dardacha-vX.Y.Z.apk` pour le télécharger, puis
   l'ouvrir.
3. Android demande d'autoriser l'installation depuis le navigateur : accepter
   (une seule fois).

Pas de version iPhone pour l'instant.

## 2. Créer un compte GitHub (une seule fois)

Les signalements arrivent sur GitHub, le site qui héberge le projet. Créer un
compte gratuit sur https://github.com/signup et rester connecté dans le
navigateur du téléphone.

## 3. Relire

Parcourir les séances comme un apprenant. Sous chaque expression, un lien
**« ⚑ Signaler »** ; en bas de chaque séance, **« ⚑ Signaler une erreur dans
cette page »** pour les textes (objectif, contexte, consignes, à retenir).

En touchant le lien, un formulaire s'ouvre dans le navigateur, **déjà
rempli** avec la séance, l'expression et ses formes actuelles. Il reste à :

1. choisir la **variante** concernée ;
2. écrire la **forme proposée** (transcription latine, écriture arabe, ou
   les deux) ;
3. si utile, une **explication** : usage, région, registre, masculin ou
   féminin ;
4. indiquer si vous êtes **natif** de cette variante ;
5. toucher le bouton de validation (**« Create »** ou **« Submit new
   issue »**).

Un signalement par erreur, c'est plus simple à traiter.

## Ce qui nous intéresse le plus

- Une expression **qu'on ne dit pas** ainsi au quotidien, ou trop
  littéraire pour la darija ou le tounsi.
- Une **traduction française** inexacte.
- L'**écriture arabe** : il n'existe pas d'orthographe officielle de la
  darija ni du tounsi ; nous visons l'usage courant (comme sur les réseaux
  sociaux).
- La **transcription latine** : elle suit les chiffres du chat (3 = ع,
  7 = ح, 9 = ق…), sans marquer les voyelles longues.
- La **prononciation** de la voix de synthèse n'est pas à signaler : elle
  dépend du téléphone, pas du contenu.

## Ensuite

Chaque signalement est corrigé dans le contenu, puis publié dans une
nouvelle version. Un module entièrement relu perd l'avertissement « en cours
de relecture ».
